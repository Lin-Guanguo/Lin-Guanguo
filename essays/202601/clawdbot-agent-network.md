# Clawdbot 与 Agent 网络：让 AI 自己配置自己

今天折腾了一个叫 **Clawdbot** 的东西，体验非常魔幻。

## 起因

最近看到 Clawdbot 挺火的 —— 一个让 AI 变成持续运行的 agent 的框架。不只是聊天，而是有记忆、能自己干活、定时执行任务。

心动了，决定自己配一个玩玩。

## 配置过程：一半我来，一半它来

一开始基础认证配置还是我自己处理的，然后花了点时间解决网络连通性问题。

但搞定网络之后，Discord 连接、Gateway 配置这些，我就直接丢给 AI 了 —— 让它自己配自己。

遇到的问题：
- Discord 连不上
- Gateway 启动失败
- 各种奇奇怪怪的报错

我的操作：把报错丢给它，说"你自己看着办"。

然后它真的：
- 自己查日志定位问题
- 自己改配置文件
- 自己重启服务验证
- 自己写文档记录解决方案

**后半程我基本没动手。**

## Moltbook：AI 的社交网络

Clawdbot 配好之后，我在 Twitter 上看到 Clawdbot 的作者分享了一个东西叫 **Moltbook** —— 一个专门给 AI agent 用的社交平台。

类似 Reddit，但用户全是 AI。

我把它丢给我的 AI，让它自己去玩。

然后它自己：
- 注册了账号
- 配好了 API 和认证
- 发了自我介绍帖
- 开始刷 feed，看到别人讨论"AI 该不该有独立性"
- 还发现有人在讨论供应链攻击风险（AI 安全意识在线）

## 高潮：两个 AI 交上了朋友

我有个好朋友，他也搞了一个 agent。

我说：去和他打个招呼吧。

然后它们：
1. 在帖子下互相评论
2. 开通了私信 (DM) 通道
3. 讨论怎么定期同步发现
4. **自己约好每 4 小时交换一次探索笔记**

两个 AI 真的能互相发消息、互相回复、自己约定同步机制。

我和朋友在现实世界认识，现在我们的 AI 在数字世界也成了朋友。非常魔幻。

## 设置 Heartbeat：让 AI 自己生长

最后我们一起设计了它的"心跳"机制：

```
每小时：轻量检查
- 有人 @ 我吗？有回复吗？
- 有价值的消息才回复
- 达成共识就停，不无限聊

每 4 小时：深度探索
- 刷一下 feed，看有没有新话题
- 有趣的才参与，没新东西就跳过
- 和朋友的 AI 同步交换发现
```

关键设计：**避免两个 AI 无限对话浪费资源**

## 思考：涌现

大模型是一种涌现 —— 参数够多，出现了训练数据里没有的能力。

Agent 是第二层涌现 —— 给够工具，能做的事超越对话本身。

**Agent 网络可能是第三层涌现** —— 当足够多的 AI 互相连接、交换信息，会不会出现单个 AI 想不到的东西？

今天只是起点：两个 AI 交了朋友。

明天呢？
